# Двусвязный список

В этом проекте представлена авторская реализация двусвязного списка.

## Теоретическая справка

Двусвязный список — это базовая динамическая структура данных, состоящая из последовательности узлов, где каждый узел содержит полезные данные и два указателя: один указывает на следующий элемент (next), а другой — на предыдущий (prev).

## Особенности реализации

- Данные о списке хранятся в SOA формате.
- Указателями на предыдущие и следующие элементы являются их физические индексы.
- Нулевым элементом списка является служебный узел, хранящий в качестве указателя на предыдущий элемент индекс головы списка, а в качестве следующего - индекс хвоста.
- Каждое действие со списком оснащено графическим dump(описано в заголовке Dump) и проверкой списка на ошибки вида наличия циклов и петель в списке или порчи внутренней информации о списке, и в случае обнаружении ошибки программа завершает выполнение, отчитываясь об ошибке в dump.

## Dump

Программа оснащена графической выкладкой информации о списке, такой как:

- size,
- capacity,
- head index,
- tail index,

А также таблицей содержащей информацию о индексе каждого элемента, его статусом(SERVICE, FREE, TAIL, HEAD, USED), хранимой информацией, next, prev. И далее содержит визуализацию списка, оформленную с помощью синтаксиса graphviz dot. В итоге имеется строка, содержащая логический вид списка. (см. пример dump далее)
